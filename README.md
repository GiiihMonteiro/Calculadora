## Calculadora

# 📌 Sobre o Projeto:

Calculadora funcional desenvolvida para realizar operações matemáticas básicas. A aplicação foi criada com foco em
lógica de programação, na manipulação de eventos e na atualização dinâmica da interface, oferecendo uma experiência
simples e intuitiva.

---

# ⚙️ Funcionalidades:

- Realização de operações matemáticas básicas (adição, subtração, multiplicação e divisão).
- Entrada de valores por meio de botões interativos.
- Atualização do visor em tempo real conforme as ações do usuário.
- Botão para limpar os dados e reiniciar os cálculos.

---

# 🛠️ Tecnologias Utilizadas:

- HTML5 para estrutura da aplicação.
- CSS3 para estilização da interface.
- JavaScript para a lógica dos cálculos e manipulação de eventos.

---

# 🎯 Objetivo do Projeto:

- Praticar lógica de programação em JavaScript.
- Trabalhar a manipulação de eventos do DOM.
- Integrar funcionalidades com uma interface visual.
